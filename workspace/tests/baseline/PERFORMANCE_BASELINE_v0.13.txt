- Headless suite is dominated by PySide6 import time (~0.15 s).
  If the selftest refactors to avoid PySide6 import, expect < 0.05 s.

    - Board parse and graph construction
    - Dijkstra path tracing for 284 vectors
    - Zone mesh computation (V22 ladder-vs-mesh comparison)
  SciPy-accelerated sparse solver would reduce CPU-bound phases.
- IP5385 report suite (9.5 s) is dominated by board parse and 11-pair
  network solution; shares board-load time with the selftest but runs
  a different code path (run_report vs run_selftest).
